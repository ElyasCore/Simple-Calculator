Simple Calculator

A simple Java console calculator that performs basic arithmetic operations using two user-entered numbers and a selected operator.

The project focuses on practicing conditional logic, switch, loops, and input validation while handling basic arithmetic operations.

Features
Enter two numbers
Choose between addition, subtraction, multiplication, and division
Validate the selected operation
Handle division by zero
Ask for a valid number when division by zero is attempted
Display the calculated result
Concepts Practiced

Scanner · Variables · double · char · if/else · switch · while · break · Arithmetic Operators · Input Validation

Built as part of my Java learning journey to practice combining user input, conditions, loops, and switch statements into a single program.
